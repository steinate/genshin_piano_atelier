# genshin_piano_atelier

雷电将军 PMX 钢琴演出网页。入口为 `index.html`；HTML、PMX、贴图和背景使用相对路径，需放在同一 HTTP 站点中。

## 本地查看

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/`，点击播放以启用浏览器音频。

## 手部动作与回归检查

PMX 手部采用绑定姿态校准的屈曲轴、受限指根侧摆和联动末节关节，不改变指骨长度。分手规划检查持续音之间的音高次序。手部姿态按乐谱时间平滑，并在平滑后重新检查指骨胶囊间距和真实蒙皮顶点相对琴键表面的高度。

已安装 Node.js 和 Playwright 的环境可运行：

```sh
node tests/hand-motion.cjs
```

本地 HTTP 服务需先启动。可设置 `PIANO_URL`、`BROWSER_CHANNEL`、`PLAYWRIGHT_MODULE` 和 `ARTIFACT_DIR`。默认测试输出位于 `/tmp/orbit-hand-validation/`，包含两首曲目的测量结果和浏览器截图。

测试覆盖《原神》登陆主题与《Cornfield Chase》的起音后采样、每秒采样、换音过渡、跳转复现、指序、指骨长度、手指间距和琴键穿插。连续播放性能和冷缓存跳转耗时分别记录。

这些检查验证动作形态与碰撞约束，不代表所有音符均准确触达。密集持续音可能超过十指容量，模型原始手长也会限制和弦跨度；未分配事件和实际触键误差需分别查看。原曲音高、起止时间及音频内容不会为迎合动作而改写。
